## 🎯 What is this?

A growing collection of small web tools, hosted as a static site on GitHub Pages. Each tool is a single page that runs in your browser, so your files and equations are never sent to a server.

---

## 🔀 Flowchart Visualizer

**Design in text. View in motion.**

Turn a simple YAML file into an interactive, clickable flowchart.

- 📄 Upload a YAML file and get a flowchart instantly
- 🖱️ Click through the nodes to explore the flow
- 💾 Download the finished flowchart
- 🧪 Not sure where to start? [Open the sample YAML](docs/assets/flowchart_sample.yml)

> Built with architects, DevOps engineers and platform teams in mind: describe a process as text, then share it as a diagram.

👉 **[Open Flowchart Visualizer](https://hclpandv.github.io/web-tools/flowchart.html)**

## 📈 GraphLab: Math Equation Plotter

**Explore equations in 2D and 3D.**

Type an equation and see the graph straight away.

- 📐 **2D plots:** lines, parabolas, circles, ellipses, hyperbolas and trigonometric curves
- 🧊 **3D plots:** spheres, cylinders, cones, paraboloids and trigonometric surfaces
- 🎓 **Built-in examples:** pick one from the dropdown, then change the numbers and watch the graph respond
- ✍️ **Simple syntax:** write `x^2 + y^2 = 16` or `y = sin(x)`. Use `*` for multiplication and radians for angles.

👉 **[Open GraphLab](https://hclpandv.github.io/web-tools/graph-lab.html)**

## 🔒 Privacy

Everything runs client-side in your browser. Nothing you upload or type is stored or sent anywhere by these tools.

---

## 💻 Run Locally

```bash
git clone https://github.com/hclpandv/web-tools.git
cd web-tools
# serve the docs folder with any static server, for example:
python -m http.server 8000 --directory docs
```

Then open **http://localhost:8000**.
