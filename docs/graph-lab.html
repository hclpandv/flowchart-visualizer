Math Equation Plotter

Explore mathematical equations in two and three dimensions.

2D Equation

Enter equations using x and y. Examples: y = sin(x), x^2 + y^2 = 16. Trigonometric functions use radians.

3D Equation

Enter equations using x, y and z. For example, x^2 + y^2 + z^2 = 25. Use * for multiplication. Trigonometric functions use radians.

How to write equations

1. Powers: Use ^ for exponents. Example: x^2 + y^2 = 16

2. Multiplication: Always use *. Write 2*x, not 2x.

3. Trigonometry: Use sin(x), cos(x) and tan(x). Angles are in radians.

4. Square roots: Use sqrt(x^2 + y^2).

5. Equations: Use a single equals sign, such as y = x^2 or x^2 + y^2 = 16.

6. Variables: The 2D tab uses x and y. The 3D tab uses x, y and z.

Experiment: Change the numbers in an equation and observe how the graph changes.
